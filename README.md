# Bigfoot

A web map of reported Bigfoot sightings, starting with the Trail Cam mockup.

Open `index.html` locally, or use the live Railway deploy after GitHub pushes.

- **Trail Cam** — infrared map (primary design)
- Ranger Log and Contour Ops — alternate layouts

Sighting pins, dates, and classes come from the [BFRO Geographic Database](https://www.bfro.net/GDB/). Full write-ups stay on BFRO.

Pushes to `main` on [asujeff48/BigFoot](https://github.com/asujeff48/BigFoot) deploy to [Railway](https://railway.com/project/8f764e20-1128-4910-bf19-59c6dbac14ef).
